# OCFO QBR Enablement

Internal HLS enablement deck for **Selling to the Office of the CFO** — AMER IND QBR walkthrough (~45 min). Trust proofs, SOX language, finance calendar, demo contract, and LOB→OCFO expansion.

## Open locally

```bash
open presentations/ocfo-qbr-enablement-walkthrough.html
# or from repo root after clone:
open index.html
```

Speaker notes open from the **Open speaker notes** button (or open `speaker-notes.html` / `presentations/ocfo-qbr-enablement-speaker-notes.html`).

Arrow keys / Space navigate. Notes stay in sync with the deck.
